# Slugcat-pet
# WORK IN PROGRESS
Desktop pet referenced from slugcat (Rain World)

## Built With
- **Language:** Javascript
- **Framework:** Electron.js

## How to install

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your PC.

1. Download the repository
2. Open console (cmd.exe) and navigate to source file
3. Install dependencies (npm install)
4. Run the application (npm start) / (npx electron .)
